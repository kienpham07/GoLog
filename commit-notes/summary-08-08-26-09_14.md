## Overview

This commit introduces a full-stack real-time **WebSocket Streaming Engine** across both the Go backend and Next.js frontend. 

On the backend, a thread-safe Gorilla WebSocket Hub manages client connections, connection keep-alives (ping/pong), and JSON event broadcasting (`log_entry` and `stats_update`). A Gin middleware automatically captures live HTTP traffic and broadcasts log entries to connected subscribers. In addition, new log file uploads and simulated traffic events trigger real-time broadcasts. The JWT authentication middleware has been updated to accept tokens via URL query parameters (`?token=...`) to support browser WebSocket Handshakes.

On the frontend, two custom React hooks (`useWebSocket` and `useLogStream`) manage WebSocket lifecycles with exponential backoff auto-reconnection. A new `LiveLogFeed` component renders real-time streaming logs with status badge highlights, response times, and auto-scroll controls on the dashboard.

In [main.go](file:///home/kienpham07/Downloads/Disk%20D%20Window/My%20project%2010%20-%20Web%20Log%20Analyzer/backend/cmd/main.go), a Gin middleware captures and broadcasts live HTTP request traffic to all connected clients:
```go
router.Use(func(c *gin.Context) {
	start := time.Now()
	c.Next()

	if strings.HasPrefix(c.Request.URL.Path, "/api/logs/stream") {
		return
	}

	payload, err := json.Marshal(gin.H{
		"type": "log_entry",
		"data": gin.H{
			"ip":            c.ClientIP(),
			"method":        c.Request.Method,
			"endpoint":      c.Request.URL.Path,
			"status":        c.Writer.Status(),
			"bytes":         c.Writer.Size(),
			"response_time": time.Since(start).Milliseconds(),
			"timestamp":     time.Now().UTC().Format(time.RFC3339),
		},
	})
	if err == nil {
		hub.Broadcast <- payload
	}
})
```

ws.onclose = () => {
  if (!isMountedRef.current) return;
  setIsConnected(false);
  setRetryCount((prevCount) => {
    const delay = Math.min(1000 * Math.pow(2, prevCount), 30000); // 1s, 2s, 4s, 8s, max 30s
    reconnectTimerRef.current = setTimeout(() => connect(), delay);
    return prevCount + 1;
  });

## Impact

* **Instant Telemetry Updates**: Endpoints and analytics views update in real time as requests occur without requiring page refreshes.
* **Resilient Connectivity**: Built-in ping/pong heartbeats and exponential backoff reconnections guarantee stable socket connections across network interruptions.
* **Seamless Authentication**: Query parameter token support enables standard Browser WebSocket APIs (`new WebSocket(...)`) to connect securely to JWT-guarded routes.
