## Overview

This commit fixes a visual styling issue on the **Browsers** breakdown bar chart inside the Next.js frontend dashboard. 

Previously, hovering over browser category bars (such as Chrome, Firefox, Safari, or Edge) rendered the default Recharts hover cursor background fill, which appeared as a stark white block unaligned with the dark cyberpunk theme (`#0B0E14` / `#121620`). The updated configuration customizes the Tooltip cursor fill to a subtle, translucent white overlay (`rgba(255, 255, 255, 0.05)`).
