## Overview

This commit adds a **Global Time Range Picker** filter across the backend database layer and frontend dashboard components. Users can now filter log telemetry by predefined presets (**Last 24 Hours**, **Last 7 Days**, **All Time**) or specify a **Custom Date Range** (`start_date` and `end_date`). All dashboard metrics—including overview telemetries, traffic series, top endpoints, top IPs, status codes, browser breakdowns, error logs, and geographic distributions—update dynamically based on the selected timeframe.

Additionally, this commit fixes a UI layout alignment issue in table footers (Error Logs and Country Leaderboard) where uneven button widths ("Previous" vs "Next") pulled the page indicator text ("Page X of Y") off-center. Replacing standard flex containers with a 3-column grid (`grid-cols-3`) ensures page numbers remain centered.

### Parameterized SQL Date Range Queries
In [repository.go](file:///home/kienpham07/Downloads/Disk%20D%20Window/My%20project/Project%2010%20-%20Web%20Log%20Analyzer/backend/database/repository.go), a helper constructs parameterized SQL queries:
```go
func buildWhereClause(sessionID *int, startDate *time.Time, endDate *time.Time) (string, []interface{}) {
	conditions := []string{}
	args := []interface{}{}

	if sessionID != nil {
		args = append(args, *sessionID)
		conditions = append(conditions, fmt.Sprintf("session_id = $%d", len(args)))
	}
	if startDate != nil {
		args = append(args, *startDate)
		conditions = append(conditions, fmt.Sprintf("timestamp >= $%d", len(args)))
	}
	if endDate != nil {
		args = append(args, *endDate)
		conditions = append(conditions, fmt.Sprintf("timestamp <= $%d", len(args)))
	}

	if len(conditions) > 0 {
		return " WHERE " + strings.Join(conditions, " AND "), args
	}
	return "", args
}
```
