This commit extracts the time-series request chart out of the main **Dashboard** view and places it into its own dedicated navigation tab titled **Traffic Over Time**.

The new **Traffic Over Time** view features four dedicated telemetry metric cards (**Total Volume**, **Peak Interval Rate**, **Time Intervals**, and **Avg Interval Rate**), a full-width line chart graph (`LineChart`), and a **Time Bucket Breakdown Table** rendering volume share progress bars.

### Dedicated Traffic Analytics View
When `currentView === 'traffic-over-time'`, the page renders a complete analytics workflow:
1. **Four Telemetry Cards**:
   * Total Volume (`overview?.total_requests`)
   * Peak Interval Rate (`Math.max(...traffic.map(t => t.count))`)
   * Time Intervals (`traffic.length`)
   * Avg Interval Rate (`total_requests / traffic.length`)
2. **Expanded 384px Line Chart Graph**:
   * Displays continuous request timeline trends with styled dots (`#8951FF`) and dark mode tooltips.
3. **Time Bucket Breakdown Table**:
   * Renders interval timestamps, raw request counts, percentage shares, and gradient volume progress bars (`bg-gradient-to-r from-cyber-purple to-cyber-cyan`).
