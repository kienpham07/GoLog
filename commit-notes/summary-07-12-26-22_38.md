## Overview

This commit updates the visual design and UX structure of the GoLog Web Log Analyzer dashboard. It transitions the application from a basic white-and-gray administrative layout to a premium, high-fidelity dark-themed cyberpunk template. 

Alongside the structural stylesheet overhaul, the frontend code is broken down into modular presentation layouts, adding a fully responsive side navigation menu (`Sidebar`) and a contextual action bar (`TopNavigation`). Additionally, the commit standardizes key Go dependency definitions in the backend module and streamlines error status messages for easier parsing.

## Code Changes

### High-Tech Cyberpunk Theme Setup
`frontend/app/globals.css` establishes the base variables for the dark UI, configuring custom colors and hardware-style scrollbars:
```css
:root {
  --background: #0B0E14;
  --foreground: #ffffff;
}

@theme inline {
  --color-cyber-bg: #0B0E14;
  --color-cyber-card: #121620;
  --color-cyber-border: #1E2530;
  --color-cyber-purple: #8951FF;
  --color-cyber-cyan: #21C3FC;
  --color-cyber-blue: #0E43FB;
  --color-cyber-dark: #07090D;
}
```

### Component Modularity & Sidebar Implementation
The simple dashboard layout is replaced in `frontend/app/page.tsx` by introducing reusable sub-components that consume dynamic client-side filtering variables:
* **`Sidebar`**: Implements dashboard tabs, developer documentation references, profile configurations, and mobile overlay capabilities.
* **`TopNavigation`**: Contains the global search filter input, real-time alert/notification bell triggers, the active username, and a logout menu.
* **Metric Cards & Charts**: Structures telemetry metrics (Total Requests, Success Requests, Failed Requests, Unique Clients) inside modular cards with status trend vectors.

### Storage Persistence Update
`frontend/app/login/page.tsx` is updated to record the logged-in administrator's username inside the browser's persistent store:
```typescript
if (typeof window !== "undefined") {
  localStorage.setItem("golog_token", data.token);
  localStorage.setItem("golog_username", username);
}
```
This username is subsequently retrieved in the root dashboard layout to display the admin's name dynamically.

### Cleaned up Backend DBParsing Responses
`backend/cmd/main.go` error responses were simplified to align with frontend notifications:
* Registration errors: Changed from `"Username already exists or database error"` to `"Username already exists"`.
* Log insertion errors: Changed from `"Failed to save logs to database"` to `"Failed to save logs"`.
