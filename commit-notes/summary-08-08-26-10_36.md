## Overview

This commit refactors the application's primary navigation architecture by replacing the left-side drawer panel (`Sidebar`) with a unified, sticky top navigation bar (`TopNavigation`). 

The view route buttons (**Dashboard**, **Error Logs**, **Geographic Map**) are integrated directly into the top header next to the brand logo (`GoLog`) and user profile menu. Additionally, the main application container width limit is expanded from `max-w-7xl` (`1280px`) to a widescreen format (`max-w-[1720px]`), providing a more spacious layout for charts, tables, and live logs. Column max-widths in the Top Endpoints and Error Logs tables have also been widened to prevent premature text truncation.

### Widescreen Container Layout
The `<main>` content container width restriction was expanded to better utilize high-resolution monitors:
```diff
- <main className="flex-1 flex flex-col px-4 py-8 sm:px-6 lg:px-8 w-full max-w-7xl mx-auto">
+ <main className="flex-1 flex flex-col px-4 py-8 sm:px-6 lg:px-8 w-full max-w-[1720px] mx-auto">
```

### Table Column Width Expansion
Max-width constraints on table cells were increased to prevent truncating long API endpoint paths and browser User-Agent strings:
```diff
{/* Top Endpoints table path column */}
- <td className="py-3 font-mono text-cyber-cyan truncate max-w-[280px]">
+ <td className="py-3 font-mono text-cyber-cyan truncate max-w-[450px]">

{/* Error Logs table path & user agent columns */}
- <td className="py-3 font-mono text-gray-200 truncate max-w-[200px]" title={log.endpoint}>
+ <td className="py-3 font-mono text-gray-200 truncate max-w-[380px]" title={log.endpoint}>
```
