### Dynamic Country Borders & Drop-Shadow Glow Effects
In [page.tsx](file:///home/kienpham07/Downloads/Disk%20D%20Window/My%20project/Project%2010%20-%20Web%20Log%20Analyzer/frontend/app/page.tsx), dynamic map styles generate custom CSS rules based on request traffic ratios:
```typescript
const dynamicMapStyles = useMemo(() => {
  const maxCount = Math.max(...geographicStats.map(s => s.count), 1);
  return `
    #world-map path {
      fill: #151C28;
      stroke: #222C3D;
      stroke-width: 0.6;
      transition: fill 0.15s ease, stroke 0.15s ease, stroke-width 0.15s ease, filter 0.15s ease;
    }
    ${geographicStats.map(stat => {
      const code = stat.country_code.toLowerCase();
      // Calculates translucent fill, border stroke, and drop-shadow glow colors
      return `
        #world-map #${code}, #world-map #${code} path {
          fill: ${fillColor} !important;
          stroke: ${strokeColor} !important;
          stroke-width: 1.25 !important;
          filter: drop-shadow(0 0 5px ${glowColor}) !important;
        }
      `;
    }).join('\n')}
  `;
}, [geographicStats]);
```
