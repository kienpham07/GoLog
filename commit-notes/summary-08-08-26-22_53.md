## Overview

This commit implements a 13-item pagination feature for the **Time Bucket Breakdown Table** in the **Traffic Over Time** view tab. 

When analyzing logs across large time ranges (e.g. 24+ hourly buckets or multiday data), rendering all time interval rows at once resulted in an excessively long table. The updated table slices interval datasets into pages of 13 entries each, resets page indices automatically when time filters or log sessions change, and adds a 3-column grid footer showing entry range indicators, centered page numbers, and Previous/Next buttons.

## Code Changes

### Time Bucket Pagination Hooks & Slice Calculation
In [page.tsx](file:///home/kienpham07/Downloads/Disk%20D%20Window/My%20project%2010%20-%20Web%20Log%20Analyzer/frontend/app/page.tsx), pagination state and slice calculations manage interval rows:
```typescript
const [trafficPage, setTrafficPage] = useState(0);
const trafficLimit = 13;

useEffect(() => {
  setTrafficPage(0);
}, [timeRangePreset, customStartDate, customEndDate, selectedSessionID, traffic.length]);

const totalTrafficEntries = traffic.length;
const totalTrafficPages = Math.ceil(totalTrafficEntries / trafficLimit) || 1;

const paginatedTraffic = useMemo(() => {
  return traffic.slice(trafficPage * trafficLimit, (trafficPage + 1) * trafficLimit);
}, [traffic, trafficPage, trafficLimit]);

const trafficStartCount = totalTrafficEntries === 0 ? 0 : trafficPage * trafficLimit + 1;
const trafficEndCount = Math.min((trafficPage + 1) * trafficLimit, totalTrafficEntries);
```

### Paginated Table Rendering
The table maps over `paginatedTraffic` instead of the full `traffic` array:
```typescript
{paginatedTraffic.map((item, idx) => {
  const total = overview?.total_requests || 1;
  const pct = Math.min(100, Math.round((item.count / total) * 100));
  return (
    <tr key={idx} className="hover:bg-cyber-bg/30 transition-colors">
      <td className="py-3 font-mono text-gray-200">{formatHour(item.hour)}</td>
      <td className="py-3 font-mono text-right font-bold text-cyber-cyan">{formatCount(item.count)}</td>
      <td className="py-3 font-mono text-right font-bold text-gray-300">{pct}%</td>
      <td className="py-3 pl-6">
        {/* Progress bar */}
      </td>
    </tr>
  );
})}
```

### 3-Column Footer Pagination Controls
A grid footer renders entry range statistics, centered page numbers, and navigation controls:
```typescript
<div className="grid grid-cols-3 items-center w-full mt-6 border-t border-cyber-border/40 pt-4">
  <div className="flex justify-start items-center">
    <span className="text-xs text-gray-400 font-mono">
      Showing {trafficStartCount}–{trafficEndCount} of {totalTrafficEntries} entries
    </span>
  </div>

  <div className="text-center">
    <span className="text-xs text-gray-300 font-bold font-mono">
      Page {trafficPage + 1} of {totalTrafficPages}
    </span>
  </div>

  <div className="flex justify-end items-center gap-2">
    <button
      type="button"
      disabled={trafficPage === 0 || loading || totalTrafficEntries === 0}
      onClick={() => setTrafficPage((p) => p - 1)}
    >
      Previous
    </button>
    <button
      type="button"
      disabled={trafficPage >= totalTrafficPages - 1 || loading || totalTrafficEntries === 0}
      onClick={() => setTrafficPage((p) => p + 1)}
    >
      Next
    </button>
  </div>
</div>
```

## Impact

* **Clean Layout Height**: Caps the maximum vertical height of the Time Bucket Breakdown Table to 13 rows.
* **Filter Synchronization**: Automatically resets pagination back to Page 1 whenever session files or time range filters are changed.
