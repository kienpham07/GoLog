## Overview

This commit introduces a multi-view tabbed navigation architecture to the frontend dashboard. It updates the left navigation menu (`Sidebar`) to host two active channels: **Dashboard** and **Error Logs**. 

To optimize performance and unclutter the user interface, the paginated **Error Logs** table is completely decoupled from the bottom of the main dashboard analytics workspace and extracted to its own dedicated **Log Management** view. Additionally, local font loaders are cleaned up in favor of standard fallback system fonts, and the application metadata has been updated to reflect the GoLog brand.

## Code Changes

### Multi-View State Management
A view state switcher hook is introduced in [page.tsx](file:///home/kienpham07/Downloads/Disk%20D%20Window/My%20project/Project%2010%20-%20Web%20Log%20Analyzer/frontend/app/page.tsx) to govern active UI panels:
```typescript
const [currentView, setCurrentView] = useState<'dashboard' | 'error-logs'>('dashboard');
```
This state is piped into the `Sidebar` component to control current views and handle state mutations:
```typescript
<Sidebar
  isOpen={isSidebarOpen}
  onClose={() => setIsSidebarOpen(false)}
  currentView={currentView}
  onViewChange={setCurrentView}
/>
```

### Sidebar Menu List and Styles
The navigation bar in the sidebar now renders active indicators dynamically. Clicking an option sets the active view and closes the sidebar drawer:
```typescript
{/* Dashboard view link */}
<button
  type="button"
  onClick={() => {
    onViewChange('dashboard');
    onClose();
  }}
  className={`flex w-full items-center gap-3 rounded-lg px-3 py-2 text-xs font-bold transition ${
    currentView === 'dashboard'
      ? 'bg-cyber-purple text-white shadow-[0_0_15px_rgba(137,81,255,0.4)]'
      : 'text-gray-400 hover:bg-cyber-bg hover:text-white'
  }`}
>
  <DashboardIcon className="h-4 w-4 shrink-0" />
  <span>Dashboard</span>
</button>
```

### Decoupled Content Layout
The main dashboard workspace is divided into two mutually exclusive views:
```typescript
<main className="flex-1 px-4 py-8 sm:px-6 lg:px-8 w-full max-w-7xl mx-auto">
  {currentView === 'dashboard' ? (
    <>
      {/* 1. Overview Telemetry Cards */}
      {/* 2. Upload Sessions / Controls */}
      {/* 3. HTTP Methods Bar Chart */}
      {/* 4. Success Trends Area Chart */}
      {/* 5. Top Pages Table & Top IPs Table */}
    </>
  ) : (
    <>
      {/* 6. Log Management Heading */}
      {/* 7. Paginated Error Log Table & Filters */}
    </>
  )}
</main>
```

### Font Asset Clean-up & Metadata
Google Font bindings are removed in [layout.tsx](file:///home/kienpham07/Downloads/Disk%20D%20Window/My%20project/Project%2010%20-%20Web%20Log%20Analyzer/frontend/app/layout.tsx):
```diff
-import { Geist, Geist_Mono } from "next/font/google";
-const geistSans = Geist({ variable: "--font-geist-sans", subsets: ["latin"] });
-const geistMono = Geist_Mono({ variable: "--font-geist-mono", subsets: ["latin"] });
```
Instead, [globals.css](file:///home/kienpham07/Downloads/Disk%20D%20Window/My%20project/Project%2010%20-%20Web%20Log%20Analyzer/frontend/app/globals.css) relies on system font stacks:
```css

--font-mono: ui-monospace, SFMono-Regular, Menlo, Monaco, Consolas, monospace;
```

## Impact

* **Improved Performance**: The main page no longer handles large paginated error lists simultaneously with live charts, reducing browser redraw weights.
* **Distinct Views**: Separates general analytics reports from raw developer diagnostics logs.
* **Simplified Assets**: Reduces index weight by removing active web font fetches.
