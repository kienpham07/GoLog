## Overview

This commit implements a geographic visualization dashboard in the frontend and introduces a geolocation classification engine on the backend. The Go server geolocates request IP addresses to mapping coordinates and returns country hit statistics.

On the frontend, an interactive SVG-driven **World Map** component charts traffic coordinates with scaled heat dots and active country color fills. Hovering over active regions displays contextual tooltips indicating the request quantity, coordinates, and percentage share. A sidebar leader board ranks origin traffic locations in descending order.

```go
func GeolocateIP(ipStr string) GeoInfo {
	ip := net.ParseIP(ipStr)
	if ip == nil {
		return countriesList[0] // fallback US
	}
	ip4 := ip.To4()
	if ip4 != nil {
		firstOctet := int(ip4[0])
		switch firstOctet {
		case 8, 34, 52, 54, 72, 74, 104, 107, 108, 172:

		// Additional country block ranges...
```

### Interactive Heatmap Dots & Coordinate Conversions
In [page.tsx](file:///home/kienpham07/Downloads/Disk%20D%20Window/My%20project/Project%2010%20-%20Web%20Log%20Analyzer/frontend/app/page.tsx), coordinates map to the SVG canvas using a projection formula:
```typescript
const getCoordinates = (stat: { country_code: string; latitude: number; longitude: number }) => {
  const code = stat.country_code.toUpperCase();
  if (countryCoords[code]) {
    return countryCoords[code];
  }
  const x = 405 + 2.17799 * stat.longitude;
  const y = 512 - 2.6 * stat.latitude;
  return { x, y };
};
```
Within the `<WorldMap>` container, countries are highlighted via dynamic inline CSS properties, and traffic concentration points render pulsing radial circles styled based on volume ratios:
* **Ratio > 0.6**: Crimson Red (`#EF4444`)
* **Ratio > 0.2**: Cyber Purple (`#8951FF`)
* **Lower Volume**: Cyber Cyan (`#21C3FC`)
